# 📦 Supply Chain Demand Forecasting System

An interactive Machine Learning web application built with **Streamlit** to solve classic supply chain and logistics problems: **preventing overstock and avoiding understock.** 

This project demonstrates how data-driven decision-making can optimize inventory management by forecasting weekly product demand based on historical sales, pricing dynamics, and promotional events.

## 🌟 Key Features
- **Exploratory Data Analysis (EDA):** Interactive Plotly charts visualizing overall sales trends, seasonality, and the impact of promotions.
- **Data Dictionary:** Comprehensive explanation of all features and planned feature engineering steps.
- **Interactive Preprocessing:** (Work in Progress) User-defined data splitting and feature extraction.
- **Model Training:** (Work in Progress) Training a **Random Forest Regressor** to capture non-linear relationships between price drops, features, and demand.
- **Prediction Demo:** (Work in Progress) A real-time scenario simulator where users can input price and promotion status to estimate required inventory.

## 🛠️ Tech Stack
- **Language:** Python
- **Frontend/Framework:** Streamlit
- **Data Manipulation:** Pandas, NumPy
- **Machine Learning:** Scikit-Learn (Random Forest)
- **Data Visualization:** Plotly
